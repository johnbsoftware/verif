Politique de confidentialité

Application Vérif (fr.johnbsoftware.verif) · JohnB Software · mise à jour le 24 septembre 2026

En bref : Vérif ne collecte aucune donnée personnelle. Il n'y a ni compte, ni publicité, ni outil de mesure d'audience. Rien de ce que vous faites dans l'appli n'est envoyé à l'éditeur.

Ce qui reste sur votre téléphone

  • Vos réglages (pays, thèmes, apparence, rappel quotidien) et les vérifications que vous enregistrez.
  • Une copie du flux des vérifications et des résumés d'articles déjà lus, pour l'usage hors connexion.

Ces données sont supprimées avec l'appli, ou via Paramètres → Applications → Vérif → Stockage → Effacer les données.

Connexions effectuées par l'appli

  • Flux des vérifications : téléchargé depuis GitHub Pages (johnbsoftware.github.io), à l'ouverture et, si vous activez le rappel quotidien, une fois par matin. Comme tout serveur web, GitHub reçoit l'adresse IP de la requête (voir la déclaration de confidentialité de GitHub).
  • Articles de vérification : quand vous ouvrez une vérification, l'appli peut lire le résumé publié sur le site de l'organisme (AFP, TF1 Info…), comme le ferait votre navigateur.
  • Contenu partagé vers Vérif : si vous partagez un lien, l'appli lit la page publique de ce lien et, pour TikTok, X et YouTube, leur service d'aperçu officiel (oEmbed) pour récupérer le texte du post. Le lien est alors transmis au service concerné, uniquement à votre demande.
  • Recherche d'image : le bouton « Rechercher avec Google Lens » transmet l'image à l'appli Google, uniquement quand vous le touchez.

Lecture du texte des images

Le texte d'une capture d'écran partagée est lu sur le téléphone par ML Kit (services Google Play), sans envoyer l'image. Google peut recevoir des statistiques techniques d'utilisation de ce module (voir les conditions de ML Kit).

Notifications

Le rappel quotidien est facultatif. Il est calculé sur le téléphone à partir du flux public ; aucun identifiant de notification n'est transmis à un serveur.

Enfants

Vérif ne s'adresse pas spécifiquement aux enfants et ne collecte aucune donnée les concernant.
